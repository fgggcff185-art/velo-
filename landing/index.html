        الميزات
        
كل ما يحتاجه المطور… في نافذة واحدة

        
بدون ملحقات خارجية، Velo يأتي جاهزاً بالأدوات التي تستخدمها كل يوم.

      


      

        
        

          

            
          

          
محرر Monaco متكامل

          
نفس المحرر الذي يعمل داخل VS Code، مع تلوين لغوي، Minimap، طي الكود، أرقام الأسطر، ودعم أكثر من 50 لغة.

        


        
        

          

            
          

          
إدارة التبويبات

          
افتح عدة ملفات، تتبّع التعديلات غير المحفوظة، أعد ترتيب التبويبات وأغلقها بضغطة واحدة.

        


        
        

          

            
          

          
مستكشف الملفات

          
افتح مجلدات كاملة، أنشئ واحذف وأعد تسمية الملفات والمجلدات من شجرة افتراضية سريعة.

        


        
        

          

            
          

          
طرفية حقيقية (PTY)

          
تشغيل npm و git و python مباشرة عبر node-pty مع PowerShell و CMD، وتقسيم الطرفيات.

        


        
        

          

            
          

          
مساعد الدردشة AI

          
دردش مع الذكاء الاصطناعي مع إرفاق ملفات ومجلدات كاملة كسياق، وعرض الردود مع تظليل الكود.

        


        
        

          

            
          

          
Team: Architect → Coder → Reviewer

          
ثلاثة وكلاء يعملون كفريق واحد: المعماري يصمم، المبرمج يكتب الملفات فعلياً، والمراجع يفحص. مع تصحيح ذاتي عند touchedFiles.size === 0.

          جديد
        


        
        

          

            
          

          
MCP Tools

          
دعم بروتوكول Model Context Protocol لاستدعاء الأدوات الخارجية وتنفيذ الأوامر تلقائياً من داخل الدردشة.

        


        
        

          

            
          

          
لوحة Git

          
تابع الملفات المعدّلة، استعرض Diff وأجرِ Commit مباشرة من الواجهة دون مغادرة المحرر.

        


        
        

          

            
          

          
بحث شامل + RegEx

          
ابحث في كل ملفات المشروع دفعة واحدة، مع دعم التعبيرات النمطية والاستبدال (Replace).

        


        
        

          

            
          

          
شريط الأوامر (Ctrl+Shift+P)

          
وصول فوري لكل الوظائف والإعدادات بدون حفظ اختصارات. اكتب جزءاً من اسم الأمر وستجده.

        


        
        

          

            
          

          
عارض الفروقات (Diff)

          
قارن بين نسختين من أي ملف في شاشة مزدوجة مع تظليل الإضافات والحذوفات.

        


        
        

          

            
          

          
Ghost Text (إكمال ذكي)

          
اقتراحات كود بألوان رمادية خفيفة أثناء الكتابة، اضغط Tab للقبول. مدمج مع نماذج الذكاء.

        


        
        

          

            
          

          
تعديل موضعي (Ctrl+K)

          
حدّد أي جزء من الكود واطلب تعديله بلغة طبيعية، يُستبدل مباشرة داخل المحرر.

        

      

    

  


  
  

    

      

        الذكاء الاصطناعي
        
فريق من الوكلاء يعيش داخل كودك

        
من محادثة بسيطة إلى مشروع كامل يُكتب أمامك.

      


      

        

          
01

          
دردشة سياقية

          
أرفق ملفاتك واطرح سؤالك. الـ AI يقرأ مشروعك قبل أن يجيب، ويقتبس السطور بالأرقام.

        

        

          
02

          
وضع الوكيل Agent

          
يقرأ المشروع، يخطط، ثم ينشئ ويعدل الملفات مباشرة عبر أدوات write_file و read_file.

        

        

          
03

          
وضع الفريق Team

          
ثلاثة أدوار متسلسلة: Architect يصمم، Coder يكتب، Reviewer يفحص ويصحح. مع إصلاح تلقائي عند فشل أي دور.

        

        

          
04

          
سجل المحادثات (Realm)

          
كل محادثاتك محفوظة على القرص بشكل مشفّر. ارجع لأي محادثة قديمة، احذفها، أو تصفح آخر 20 جلسة بضغطة واحدة.

export function slugify(input: string): string {
  return input
    .toLowerCase()
    .trim()
    .replace(/[^\w\s-]/g, '')
    .replace(/\s+/g, '-')
    .replace(/-+/g, '-');
}
